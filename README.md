# Real Madrid FC Fan Website

## Project Description

This project is a multi-page Real Madrid FC fan website created as part of Frontend Assignment 6.

The website provides information about Real Madrid, its players, history, tickets and fan community. It includes interactive features, search functionality, dynamic lists and form validation.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- jQuery 3.7.1
- Bootstrap 5.3.3
- Responsive Web Design

## Website Pages

1. **Home** – Introduction to Real Madrid FC.
2. **Squad** – Information about the first-team players.
3. **History** – Club history, achievements and legends.
4. **Tickets** – Match and ticket information.
5. **Contact** – Contact form with validation.
6. **Fan Zone** – Interactive fan features and FAQ section.
7. **Register** – Fan club registration form.

## Main Features

### Task 1: jQuery Selectors and Events
- Personalized welcome message.
- Input validation for the visitor's name.
- Dark and light theme switching.
- jQuery event handling using `.on()`.

### Task 2: FAQ Animations
- Interactive FAQ accordion.
- Slide up and slide down effects.
- Fade animations.
- Accessible buttons with `aria-expanded`.

### Task 3: Search and Filtering
- Live player search.
- Case-insensitive search.
- Category filtering.
- Dynamic result counter.
- No-results message.

### Task 4: Dynamic List
- Add new favourite players.
- Remove items without reloading the page.
- Empty input validation.
- Dynamic item counter.
- Delegated click events.

### Task 5: Form Validation
- Contact form validation.
- Registration form validation.
- Email format checking.
- Password length validation.
- Password confirmation.
- Success and error messages.

## How to Run the Project

1. Download or extract the project folder.
2. Open the project in Visual Studio Code.
3. Open `index.html` in a web browser.
4. Navigate through the website using the navigation menu.

An internet connection is required for external CDN libraries such as jQuery and Bootstrap.

## Testing

The website should be tested for:

- Navigation between all pages.
- Form validation and error messages.
- Search and category filtering.
- FAQ accordion animations.
- Adding and removing favourite players.
- Responsive layout on different screen sizes.
- Browser compatibility.

## Important Note

This is an educational frontend project. Registration, contact and ticket interactions are demonstrations only. No real accounts are created, and no information is sent to or stored on a backend server.

## Conclusion

The project demonstrates the use of HTML, CSS, JavaScript, jQuery, Bootstrap, responsive design, interactive elements and frontend form validation.
